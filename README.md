Curso el Máster en Ciberseguridad y Hacking Ético y busco mi primer puesto en **SOC / Blue Team**, **soporte IT** o **administración de sistemas**.

Esta web crece conmigo: cada laboratorio, certificación o proyecto nuevo termina aquí.

## Cómo está hecha

| | |
|---|---|
| **Sin frameworks** | HTML, CSS y JavaScript escritos a mano |
| **Privacidad** | Sin cookies, sin analítica y sin peticiones a terceros; tipografías alojadas en el propio repositorio |
| **Seguridad** | Content Security Policy, enlaces externos con `noopener noreferrer`, DOM modificado solo con `textContent`, correo protegido frente a bots, CV sin metadatos y [`security.txt`](https://davidpoww.github.io/.well-known/security.txt) (RFC 9116) |
| **Accesibilidad** | HTML semántico, navegación completa con teclado, textos para lectores de pantalla y respeto a `prefers-reduced-motion` |
| **Bilingüe** | Español e inglés en páginas separadas, enlazadas con `hreflang` |
| **Tipografía** | Sin líneas huérfanas, sangría francesa y puntuación colgante |

## Ejecutar en local

```bash
git clone https://github.com/Davidpoww/Davidpoww.github.io.git
cd Davidpoww.github.io
python3 -m http.server 8000 --bind 127.0.0.1
```

Después, abre `http://localhost:8000`.
